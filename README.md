# HenClient Reborn

Next-generation lightweight Fabric utility client targeting **Minecraft 1.21.11**.

## Features & Modules

- **HUD & Info**: Coordinates, FPS, Health HUD, Sprint Status, Armor Status with durability warnings, Direction, Biome.
- **Exploration**: Storage Finder, Spawner Finder, Sus Chunk Finder (heuristic density scanning), Storage ESP, Freecam.
- **Combat Utilities**: Auto Clicker, Aim Assist (for singleplayer/testing environments).

## Building & Installation

To build the mod jar, run:
./gradlew build
The output jar will be in `build/libs/`.
